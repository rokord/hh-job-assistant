# HH Job Assistant

Локальный помощник для работы с hh.ru: сбор вакансий, полуавтоматические отклики, автоматические отклики по страницам, напоминания в чатах и локальный dashboard со статистикой.

Проект работает локально на Windows через Python и Playwright. Браузер запускается в видимом режиме, авторизация hh.ru сохраняется в локальном профиле.

## Возможности

- Сбор вакансий со страницы поиска hh.ru в JSON.
- Полуавтоматические отклики из списка вакансий.
- Автоматические отклики по страницам поиска.
- Автоматическая вставка сопроводительного письма.
- Blacklist компаний.
- Обработка лимита hh.ru 200 откликов / 24 часа.
- Напоминания работодателям в чатах hh.ru.
- Manual review для чатов, где работодатель прислал вопросы, форму, ссылку или тестовое.
- Локальный dashboard со статистикой запусков, откликов, follow-up и логов.
